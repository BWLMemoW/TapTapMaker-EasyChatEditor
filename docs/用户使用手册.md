## 一、它是什么，能帮你做什么

Easy-ChatBox（下文简称 EC）是一个**对话系统模块**，不是独立游戏。它跑在你的游戏里，负责：

- 逐字显示的对话 / 旁白
- 角色立绘的入场、出场、移动、表情切换、缩放、高亮
- 背景 / CG 切换与转场
- BGM / 音效播放与音量渐变
- 玩家选择分支、条件跳转、超时
- 变量（`{好感度}` 这类）的运算与跨剧本共享
- 历史回看、自动播放、快进、黑幕转场

你要做的三件事：
1. **配资源**：在 `register.json` 里告诉它有哪些角色、场景、音频、按钮图片。
2. **写剧本**：用一份极简的剧本语言（见第五节）描述剧情流程。
3. **接引擎**：在你的游戏入口调用 `EC.start / EC.update / EC.click / EC.choose`，并监听结束信号。

## 二、5 分钟快速上手

下面是一份**最小可运行**的接入示例（以某个游戏入口脚本为例）：

```lua
local UI = require "urhox-libs/UI"
local EC = require "easy-chat"

-- 1) 引擎启动时，初始化 UI 缩放（只做一次，且必须用这个值）
function Start()
    UI.Init({ theme = "default-dark", scale = UI.Scale.DESIGN_RESOLUTION(1920, 1080) })
    EC.on_finished(function(name)
        print("剧情结束：", name)   -- 回到你的游戏玩法
    end)
    SubscribeToEvent("Update", "HandleUpdate")
    SubscribeToEvent("MouseButtonUp", "HandleClick")
    SubscribeToEvent("KeyUp", "HandleKeyUp")
end

-- 2) 启动一段剧情（剧本是字符串，register 省略则用 easy-chat/register.json）
local MY_CHAT = [[
@scene bg_classroom fade 1.0
@show alice default center
alice:"你好，世界。"
@choice
- "你好呀" >> say_hi
- "再见" >> say_bye
@end
> say_hi
alice(happy):"很高兴认识你！"
>> the_end
> say_bye
alice(sad):"那……下次见。"
>> the_end
> the_end
@end
]]
EC.start(nil, MY_CHAT, "chapter1")

-- 3) 每帧推进
function HandleUpdate(eventType, eventData)
    EC.update(eventData:GetFloat("TimeStep"))
end

-- 4) 玩家点击
function HandleClick(eventType, eventData)
    if eventData:GetInt("Button") ~= MOUSEB_LEFT then return end
    EC.click()
end

-- 5) 玩家按数字键做选择
function HandleKeyUp(eventType, eventData)
    local k = eventData:GetInt("Key")
    if     k == KEY_1 then EC.choose(1)
    elseif k == KEY_2 then EC.choose(2) end
end
```

把这 5 步接好，预览即可看到角色出场、打字、出选项、分支、结束回退。

## 三、外部接线（API 参考）

所有接口都在 `EC` 命名空间下。模块文件：`scripts/easy-chat/init.lua`。

### 3.1 启动与每帧

| 接口 | 说明 |
|------|------|
| `EC.start(register, chat_source, chat_name, sources)` | 启动一段剧情。`register` 传 `nil` 则用默认 `easy-chat/register.json`；`chat_source` 是剧本字符串；`chat_name` 是给结束信号的名字（默认 `"chapter1"`）；`sources` 是 `@call` 子剧本表 `{文件名=源码}`（可选）。 |
| `EC.update(dt)` | **每帧必须调用**。传入引擎的 `TimeStep`。内部自动钳制异常 dt，保证动画插值正确。 |
| `EC.click()` | 玩家点击时调用。推进对话 / 跳过打字 / 触发选项后的继续。 |
| `EC.choose(index)` | 玩家选择第 `index` 个选项（从 1 开始）。等价于按数字键。 |
| `EC.is_finished()` | 返回 `true` 表示剧情已播完（UI 已清理）。 |

> ⚠️ **缩放初始化是红线**：调用 `EC.start` 之前，必须先用
> `UI.Init({ theme = "default-dark", scale = UI.Scale.DESIGN_RESOLUTION(1920, 1080) })`
> 初始化一次。若用别的缩放值，UI 在多种设备尺寸下会错位。

### 3.2 结束信号与状态读取

| 接口 | 说明 |
|------|------|
| `EC.on_finished(fn)` | 注册结束回调 `function(chat_name)`。剧情播完时触发一次（幂等，不会双发）。**必须传 function**，否则结束信号不回调。回调参数为 `chat_name`，即 `EC.start` 时传入的第三个参数，可据此区分是哪个剧情结束。 |
| `EC.export_globals()` | 返回当前全部变量表（副本），用于你自己的存档或跨剧情共享。 |
| `EC.import_globals(tbl)` | **在 `EC.start` 之前调用**，整体覆盖变量初始值。`tbl=nil` 则不覆盖，用 register 默认值。 |
| `EC.get_current_choices()` | 返回当前可用选项列表（无选择时返回 `nil`）。可用于自定义 HUD。 |
| `EC.get_history()` | 返回历史记录列表，每条含 `name` / `text` / `is_choice`。 |
| `EC.clear_history()` | 清空历史。切换剧情 / 新存档时调用。 |
| `EC.reveal()` | 重新触发一次淡入转场。用于「返回后重新进入剧情」时复位黑幕。 |
| `EC.get_cg_unlock_status()` | 返回全部 CG 解锁状态（哈希表）。键为 `register.scenes` 中 `type=="cg"` 的全部 id，未解锁为 `false`。供 CG 回看界面画灰/亮。 |
| `EC.get_unlocked_cgs()` | 返回已解锁 CG 的 id 数组（仅 `true` 的项）。CG 回看可直接遍历此列表。 |
| `EC.export_cg_status()` | 导出 CG 解锁表副本（玩家级存档用）。 |
| `EC.import_cg_status(tbl)` | 导入 CG 解锁表（玩家级存档读档时调用，**应在 `EC.start` 之前**）。`tbl` 非 nil 则整体覆盖；`tbl=nil` 则重置（下次 `start` 由 register 重建为全 `false`）。 |
| `EC.on_signal(name, fn)` | 注册外部信号监听器（见 3.2.2）。剧本里 `@signal <name>` 执行到时调用 `fn(name)`。同名可注册多个监听器；监听器在模块级常驻，**`EC.start` 不清空**，可在 `start` 之前/之外注册一次服务多段剧情。 |
| `EC.on_button_pressed(name, fn)` | 注册自定义功能按钮监听器（见 3.2.3）。玩家点击 `register.json` 里 `ui_elements.custom_buttons` 配的按钮（其 `signal` 字段等于 `name`）时调用 `fn(name)`。与 `on_signal` 并存、互不干扰；监听器同样模块级常驻。 |

### 3.2.1 按剧情名区分结束（监听指定剧情）

`EC.start(register, chat_source, chat_name)` 的第三个参数 `chat_name` 会原样回传给 `on_finished` 的回调。EC 是**单实例模块**——同一时刻只能有一段剧情在跑，前一段结束（或你主动放弃）后才能 `start` 下一段。所以在**不同时段**启动不同剧情时，用名字区分「哪一段结束了」：

```lua
EC.on_finished(function(chat_name)
    if chat_name == "chapter1" then
        print("第 1 章结束 → 解锁第 2 章")
        unlock_chapter_2()
    elseif chat_name == "branch_love" then
        print("恋爱分支结束 → 回到主线路")
        return_to_main_story()
    elseif chat_name == "ending_a" then
        print("A 结局 → 进入结算界面")
        show_ending_screen("A")
    end
end)

-- 第 1 章跑完后，才启动恋爱分支（串行，不是并发）
EC.start(nil, chat_chapter1, "chapter1")
-- ... 收到 chapter1 结束信号，外部玩法推进后，再在分支点：
EC.start(nil, chat_branch, "branch_love")
```

- `chat_name` 只是个字符串标识，你随便取名（如 `"chapter1"`、`"branch_love"`、`"ending_a"`）。
- 不传时默认是 `"chapter1"`。
- EC 同一时刻只跑一段剧情：**不要在前一段还没结束时调用 `EC.start`**，那会直接替换掉当前运行时，当前剧情被中断。
- 一个回调统一接收所有剧情的结束信号，按名字分流即可；不需要为每个剧情各注册一个回调（实际上 `on_finished` 只保留最后一次注册的回调）。
- 结束信号**只触发一次**（幂等），不会重复进入同一收尾逻辑。

### 3.2.2 外部信号监听：@signal

`@signal` 让剧本**主动向外发一个信号**，你的游戏可以监听并做出反应（弹窗、触发副本、刷新任务等）。它和「结束信号」是两条独立的通道：结束信号只有一段播完才发一次，`@signal` 可以在剧情中途任意位置发多次。

**剧本里怎么写**
```
@signal quest_start        # 发出名为 quest_start 的信号
@signal enemy_spawn        # 发出另一个信号
```
- 信号名是任意字符串（**无需在 register.json 预声明**）。
- 信号**不带数据载荷**——监听器只收到信号名本身。
- 默认**只取第一个参数**：`@signal foo bar` 只发 `foo`，`bar` 被忽略。

**外部怎么监听**
```lua
EC.on_signal("quest_start", function(name)
    print("收到信号：", name)        -- name == "quest_start"
    -- 这里做你的游戏逻辑：弹 toast、开副本、更新任务……
end)
EC.on_signal("enemy_spawn", function(name)
    spawn_enemy()                    -- 同名信号可注册多个监听器，都会触发
end)
```
- 剧本执行到 `@signal quest_start` 时，`fn("quest_start")` 被同步调用。
- **同一个信号名可注册多个监听器**，全部依次触发。
- 监听器在模块级常驻，`EC.start` 不会清空它——在 `start` 之前注册一次即可服务多段剧情。
- 剧本里发出但**没有对应监听器的信号名会被静默丢弃**（不报错）。

**行为要点**
- **fire-and-forget**：信号发出后立即继续下一行剧本，不阻塞、不等待外部回应。
- **快进也触发**：自动播放 / 快进模式下信号照常发出（即发即走，与 CG 解锁一致）。
- **不去重**：同一个 `@signal NAME` 在循环 / 分支里每执行一次就发一次；需要去重由你的游戏侧处理。
- **不进存档**：信号无状态，不参与 `save()` / `load_save()`。

**完整接线示例**
```lua
local EC = require "easy-chat"
local UI = require "urhox-libs/UI"

function Start()
    UI.Init({ theme = "default-dark", scale = UI.Scale.DESIGN_RESOLUTION(1920, 1080) })
    EC.on_finished(function(name)
        print("剧情结束：", name)
    end)
    -- 注册信号监听（start 之前即可，模块级常驻）
    EC.on_signal("quest_start", function(name)
        print("[信号]", name)
        UI.Toast.Show("信号：" .. name, { type = "success", duration = 2.5, showClose = true })
    end)
    EC.on_signal("enemy_spawn", function(name)
        spawn_enemy()   -- 你的游戏逻辑
    end)
    SubscribeToEvent("Update", "HandleUpdate")
    SubscribeToEvent("MouseButtonUp", "HandleClick")
    SubscribeToEvent("KeyUp", "HandleKeyUp")
end

local CHAT = [[
@scene bg_classroom fade 1.0
@show alice default center
alice:"任务开始。"
@signal quest_start          # 外部收到 → 弹 toast
@wait 1.0
alice:"敌人出现了！"
@signal enemy_spawn          # 外部收到 → 刷怪
@wait 1.0
alice:"结束。"
@end
]]
EC.start(nil, CHAT, "chapter_with_signals")
```

> 注意：上面用 `UI.Toast` 作演示（引擎内置通知组件，独立全局层、不拦截点击、自动消失）。你也可以换成自己的弹窗、任务刷新等任意逻辑——`@signal` 只负责「通知你」，怎么做由你的游戏决定。

### 3.2.3 自定义功能按钮：on_button_pressed

自定义功能按钮让你在控制栏挂一些**常驻功能按钮**（如「商店」「背包」「设置」），点击后只向外发一个信号，具体功能由你的游戏在外部实现。它和 3.2.2 的 `@signal` 是**两条并存的通道**：

- `@signal`：剧本**中途**发出的、和剧情强相关的信号（如「任务开始」「刷怪点」）。
- `on_button_pressed`：常驻 UI 按钮发出的、与剧情**无关**的功能信号（玩家随时可点，如「打开商店」）。

两者互不影响：按钮点击走 `on_button_pressed` 链路，剧本 `@signal` 语句走 `on_signal` 链路。

**配置按钮（register.json）**

在 `ui_elements` 里加 `custom_buttons` 数组（详见 4.7.11），每个按钮指定 `signal` 名。不配则控制栏只有三大按钮，行为与旧版完全一致。

**外部怎么监听**
```lua
EC.on_button_pressed("open_shop", function(name)
    print("收到按钮信号：", name)        -- name == "open_shop"
    open_shop_ui()                       -- 你的游戏逻辑：打开商店界面
end)
EC.on_button_pressed("open_bag", function(name)
    open_bag_ui()                        -- 同名信号可注册多个监听器，都会触发
end)
```
- 玩家点击对应按钮时，`fn("open_shop")` 被同步调用。
- **同一个信号名可注册多个监听器**，全部依次触发。
- 监听器在模块级常驻，`EC.start` 不会清空它——在 `start` 之前注册一次即可服务多段剧情。
- 配置了但**没有对应监听器的按钮**点击后静默丢弃（不报错、不崩）。

**行为要点**
- **纯发信号**：点击**不前进对话、不进入分支、不触发 `@choice`、不进存档**。它是「功能挂件」，和叙事流完全解耦——玩家在任意对话句点按钮都不会打断剧情。
- **常驻**：按钮一直挂在控制栏，不随剧情出现/消失。
- **快进/自动不自动触发**：按钮必须由玩家点击触发；自动播放、快进模式下不会自动发（与 `@signal` 在快进下照常发不同）。
- **无数据载荷**：监听器只收到信号名本身。

**完整接线示例**
```lua
local EC = require "easy-chat"
local UI = require "urhox-libs/UI"

function Start()
    UI.Init({ theme = "default-dark", scale = UI.Scale.DESIGN_RESOLUTION(1920, 1080) })
    EC.on_finished(function(name)
        print("剧情结束：", name)
    end)
    -- 自定义功能按钮（start 之前注册一次，模块级常驻）
    EC.on_button_pressed("open_shop", function(name)
        print("[按钮]", name)
        UI.Toast.Show("打开商店", { type = "info", duration = 2.0, showClose = true })
    end)
    EC.on_button_pressed("open_bag", function(name)
        open_bag_ui()   -- 你的游戏逻辑
    end)
    SubscribeToEvent("Update", "HandleUpdate")
    SubscribeToEvent("MouseButtonUp", "HandleClick")
    SubscribeToEvent("KeyUp", "HandleKeyUp")
end
```

> 注意：自定义按钮是「常驻 UI」而非「剧情信号」，因此**不进 SavePack 存档**、不需要在剧本里写任何语句。想要临时出现/消失的按钮（如某段剧情专属），当前版本暂不支持——如需此类能力请反馈，后续可扩展 show/hide API。

### 3.3 接线模板（宿主薄壳）

推荐把对话系统放在一个**薄壳**里：薄壳只管引擎回调 + 菜单，对话逻辑全在 EC 模块内。

```lua
local _state = "menu"   -- menu / playing / returning

function Start()
    UI.Init({ theme = "default-dark", scale = UI.Scale.DESIGN_RESOLUTION(1920, 1080) })
    EC.on_finished(function(name)
        _state = "returning"   -- 进入收尾（让结尾黑幕走完）
    end)
    _build_menu()
    SubscribeToEvent("Update", "HandleUpdate")
    SubscribeToEvent("MouseButtonUp", "HandleClick")
    SubscribeToEvent("KeyUp", "HandleKeyUp")
end

function HandleUpdate(_, eventData)
    local dt = eventData:GetFloat("TimeStep")
    if _state == "playing" or _state == "returning" then
        EC.update(dt)
    end
    if _state == "returning" then
        _return_t = (_return_t or 0) + dt
        if _return_t >= 1.0 then _state = "menu"; _build_menu() end
    end
end

function HandleClick(_, eventData)
    if eventData:GetInt("Button") ~= MOUSEB_LEFT then return end
    if _state == "playing" then EC.click() end   -- 菜单/收尾阶段不转发
end
```

历史面板打开时，点击不应穿透到剧情 —— 薄壳里判断历史面板可见即可（见 `easy_chat_host.lua` 的 `_history_visible`）。

## 四、配置：register.json

`register.json` 是「资源登记表」。EC 在启动时加载它，剧本里写的所有 ID 都必须在这里登记过，否则校验报错、运行时缺失。

文件位于 `scripts/easy-chat/register.json`（也会被打包进资源，运行时优先读打包版）。

### 4.1 顶层结构

```json
{
  "ui_elements": { ... },   // UI 组件外观（对话框/选项/按钮/历史面板等）
  "characters":  [ ... ],   // 角色：立绘、表情、名字颜色、默认位置
  "scenes":      [ ... ],   // 背景 / CG
  "audios":      [ ... ],   // BGM / 音效
  "decorations": [ ... ],   // 全屏装饰滤镜（暗角、飘雪等）
  "variables":   { ... },   // 变量初始值（数字 / 布尔 / 字符串）
  "flags":       [ ... ]    // 布尔型开关变量，初始值 false
}
```

### 4.2 角色 characters

```json
{
  "id": "alice",
  "display_name": "爱丽丝",
  "name_color": "#FF6B9D",
  "sprites": {
    "default":   "Textures/Characters/alice/default.png",
    "happy":     "Textures/Characters/alice/happy.png",
    "sad":       "Textures/Characters/alice/sad.png"
  },
  "default_expression": "default",
  "default_position": "center",
  "scale": 1.0,
  "offset": { "x": 0, "y": 0 },
  "image_name_tag": "Textures/UI/name_tag_alice.png"
}
```

- `id`：剧本里 `@show alice` 用的名字，必须唯一。
- `display_name`：对话框里显示的名字。旁白角色（如 `narrator`）留空 `""`。
- `name_color`：名字颜色，十六进制字符串。
- `sprites`：表情名 → 立绘图片路径。**剧本里 `@show alice happy` 的表情必须在这里登记**，否则报错。
- `default_expression` / `default_position`：不写表情 / 位置时的兜底值。
- `image_name_tag`：**图片姓名条**资源路径。注意：这个字段**只有在 `ui_elements.name_tag.mode` 设为 `"image"` 时才会启用**——不是填了就替代文字姓名条。而且即便开启了 image 模式，也只对「在 register 里配了 `image_name_tag` 的角色」显示图片，文字会被隐藏；没配的角色仍按 mode 的其他逻辑走。若 `name_tag.mode` 是默认的 `"inline"`，`image_name_tag` 完全不生效（姓名直接显示在对话框内）。
  ```json
  "image_name_tag": "Textures/UI/name_tag_alice.png"
  ```
- 旁白角色写法：
  ```json
  { "id": "narrator", "display_name": "", "is_narrator": true, "sprites": {} }
  ```

### 4.3 场景 scenes

```json
{ "id": "bg_classroom", "type": "background", "image": "Textures/Scenes/classroom.png", "transition": "fade" }
{ "id": "cg_confession", "type": "cg", "image": "Textures/Scenes/confession_cg.png", "transition": "fade", "duration": 2.0 }
```

- `type`：`background`（背景）或 `cg`（立绘式大图）。
- `transition`：默认转场效果（剧本 `@scene id` 不写时用的）。
- `duration`：CG 类可设自动停留时长。

> **CG 解锁自动收集**：标记为 `type=="cg"` 的场景，剧本里播到 `@scene <cg_id>` 时会自动解锁（即发即走，快进也触发），无需额外代码。外部用 `EC.get_cg_unlock_status()` / `EC.get_unlocked_cgs()` 查询，用 `EC.export/import_cg_status()` 做玩家级跨存档持久化（详见 3.2）。

### 4.4 音频 audios

```json
{ "id": "bgm_daily",    "type": "bgm", "file": "Audio/BGM/daily_life.ogg", "loop": true, "volume": 0.7 }
{ "id": "sfx_door_open", "type": "sfx", "file": "Audio/SFX/door_open.ogg", "volume": 1.0 }
```

- `type`：`bgm`（循环常驻）或 `sfx`（一次性）。
- `volume`：注册音量（被 `@bgm fade` / `unfade` 用作恢复目标）。
- 资源路径会被自动解析为引擎 URI，无需手填 uuid。

### 4.5 装饰滤镜 decorations

```json
{ "id": "vignette", "image": "Textures/UI/decor_vignette.png", "description": "暗角" }
```

剧本里 `@decoration vignette` 显示，`@decoration none` 清除。注意：装饰滤镜是**剧情临时层**，初始化后常驻的滤镜请用 `ui_elements.persistent_filter`。

### 4.6 变量与开关 variables / flags

```json
"variables": { "affection_alice": 0, "met_bob": false, "last_word": "你好" },
"flags":     [ "gave_gift", "saw_cg_confession" ]
```

- `variables`：任意初始值（数字 / 布尔 / 字符串）。
- `flags`：列表形式，全部初始化为 `false`，适合做剧情开关。

> 剧本里可以用 `@set` 新建**局部变量**（无需在 register 预声明）。但**跨剧本 / 跨存档共享**的变量，建议放在 `variables` 里，并通过 `EC.import_globals / export_globals` 传递。

### 4.7 UI 元素 ui_elements

`ui_elements` 控制对话框、选项、姓名条、按钮、历史面板等全部 UI 外观。每个组件通用规则：

- 带 `"style"` 字段的组件可设 `"default"` 或 `"custom"`：
  - `default`：用引擎内置样式（无需图片）。
  - `custom`：用你自己的切图，需配 `image` / `nine_slice`（九宫格）等。
  - **降级**：custom 模式下若图片找不到，EC 自动降级为 default 样式，不会报错崩溃。

下面按组件逐一说明（字段均为可选，不写走引擎默认值）。

#### 4.7.1 dialogue_box（对话框底板）

```json
"dialogue_box": {
  "style": "custom",
  "image": "Textures/UI/dialogue_box.png",
  "nine_slice": { "top": 16, "bottom": 16, "left": 32, "right": 32 },
  "panel_height_ratio": 0.33,
  "side_margin": "15%",
  "text_padding": { "top": 52, "right": 66, "bottom": 52, "left": 66 },
  "name_label":  { "font_size": 32, "color": "#FFD700", "offset": { "x": 24, "y": -28 } },
  "text_label":  { "font_size": 28, "color": "#FFFFFF", "max_width": 720, "line_spacing": 4 }
}
```

- `style` / `image` / `nine_slice`：custom 模式下底板切图与九宫格（顺序 `{top,bottom,left,right}`）。
- `panel_height_ratio`：对话框高度占屏幕比例（如 `0.33` = 屏高 33%）。相对屏高自适应，优于固定像素。
- `side_margin`：面板左右留白，占屏宽百分比字符串（如 `"15%"`）。
- `text_padding`：正文相对底板四边内边距（像素，设计分辨率体系），与 `nine_slice` 对齐，避免文字压到边框。
- `name_label`：名字文字样式 —— `font_size` 字号、`color` 颜色、`offset` 相对对话框的偏移 `{x,y}`。
- `text_label`：正文文字样式 —— `font_size` 字号、`color` 颜色、`offset` 偏移、`max_width` 最大宽（像素）、`line_spacing` 行间距。

#### 4.7.2 name_tag（姓名条模式）

```json
"name_tag": {
  "mode": "image",
  "style": "default",
  "image": "Textures/UI/name_tag_bg.png",
  "nine_slice": { "top": 4, "bottom": 4, "left": 12, "right": 12 },
  "offset_x": 24,
  "offset_y": -12
}
```

- `mode`：姓名条呈现方式，决定整个姓名条行为：
  - `"inline"`（默认）：姓名直接显示在对话框内，忽略 `image_name_tag`（见 4.2）。
  - `"image"`：用角色的 `image_name_tag` 图片作底板（该角色必须配了 `image_name_tag`，否则不显示图片），文字被隐藏。
  - `"above_left"` / `"above_center"`：文字浮在对话框外左上 / 居中（custom 模式会叠到底板上）。
- `style` / `image` / `nine_slice`：仅 `above_*` 模式 + custom 时生效，提供共享底板切图。`image` / `inline` 模式不使用。
- `offset_x` / `offset_y`：姓名框相对对话框左上角的偏移（像素）。

#### 4.7.3 choice_button（选项按钮）

```json
"choice_button": {
  "style": "custom",
  "image_normal": "Textures/UI/choice_btn_normal.png",
  "image_hover": "Textures/UI/choice_btn_hover.png",
  "nine_slice": { "top": 8, "bottom": 8, "left": 16, "right": 16 },
  "height": 64,
  "spacing": 14,
  "font_size": 28,
  "text_color_normal": "#CCCCCC",
  "text_color_hover": "#FFD700"
}
```

- `style` / `image_normal` / `image_hover` / `nine_slice`：custom 模式常/悬停两张切图及九宫格。
- `height`：单个选项按钮高度（像素）。
- `spacing`：多个选项之间的纵向间距（像素）。
- `font_size`：选项文字字号。
- `text_color_normal` / `text_color_hover`：常/悬停文字颜色。

#### 4.7.4 continue_indicator（继续提示箭头）

```json
"continue_indicator": {
  "style": "custom",
  "image": "Textures/UI/continue_arrow.png",
  "width": 24,
  "height": 24,
  "margin_right": 16,
  "margin_bottom": 8,
  "blink_interval": 0.8
}
```

- `style` / `image`：custom 模式箭头图标。
- `width` / `height`：箭头尺寸（像素）。
- `margin_right` / `margin_bottom`：相对对话框右下角的边距（像素）。
- `blink_interval`：闪烁周期（秒），提示玩家可点击继续。

#### 4.7.5 fast_forward_btn（快进按钮）

```json
"fast_forward_btn": {
  "style": "custom",
  "image": "Textures/UI/btn_ff_normal.png",
  "image_active": "Textures/UI/btn_ff_active.png",
  "size": 144,
  "speed_multiplier": 8.0
}
```

- `style` / `image` / `image_active`：常/激活两张图标。
- `size`：按钮边长（像素，方形）。
- `speed_multiplier`：快进时每帧推进的步数倍数（越大越快）；遇选项自动停下。

#### 4.7.6 auto_play_btn（自动播放按钮）

```json
"auto_play_btn": {
  "style": "custom",
  "image": "Textures/UI/btn_auto_normal.png",
  "image_active": "Textures/UI/btn_auto_active.png",
  "size": 144,
  "default_interval": 2.0
}
```

- `style` / `image` / `image_active`：常/激活两张图标。
- `size`：按钮边长（像素）。
- `default_interval`：自动播放时每句停留秒数（打完字后等这么久自动继续）。

#### 4.7.7 history_btn（历史按钮）

```json
"history_btn": {
  "style": "custom",
  "image": "Textures/UI/btn_history.png",
  "size": 144
}
```

- `style` / `image`：图标。
- `size`：按钮边长（像素）。
- 点击打开历史面板，回看已说过对话；打开时点击不穿透到剧情。

#### 4.7.8 history_panel（历史面板）

```json
"history_panel": {
  "style": "custom",
  "image": "Textures/UI/history_panel.png",
  "nine_slice": { "top": 24, "bottom": 24, "left": 32, "right": 32 },
  "background_color": [0, 0, 0, 200],
  "title_font_size": 26,
  "entry_name_font_size": 22,
  "entry_text_font_size": 22,
  "entry_spacing": 8
}
```

- `style` / `image` / `nine_slice`：custom 模式面板底板切图。
- `background_color`：面板背景色 `[r,g,b,a]`（0–255）。
- `title_font_size`：面板标题字号。
- `entry_name_font_size` / `entry_text_font_size`：每条历史的角色名 / 正文字号。
- `entry_spacing`：历史条目间距（像素）。

#### 4.7.9 persistent_filter（常驻滤镜）

```json
"persistent_filter": {
  "image": "Textures/UI/persistent_vignette.png",
  "opacity": 1.0,
  "image_fit": "cover"
}
```

- `image`：常驻全屏滤镜图（如暗角、色调纸纹）。
- `opacity`：不透明度 0–1。
- `image_fit`：填充方式，`cover` / `fill` 等。
- 这是**初始化后就常驻**的图层，不要和剧情临时层 `@decoration` 混用，也不要在 cleanup 中清除它。

#### 4.7.10 control_bar（控制栏布局）

```json
"control_bar": {
  "position": "top_left",
  "margin": 20,
  "spacing": 12
}
```

- `position`：控制栏位置，可选 `top_left` / `top_right` / `bottom_left` / `bottom_right`。已默认迁到 `top_left` 以规避手机端退出键。
- `margin`：控制栏距屏幕边缘的距离（像素）。
- `spacing`：栏内按钮之间的间距（像素）。

#### 4.7.11 custom_buttons（自定义功能按钮）

> 新增于 v0.1.27。让你在不改内部代码的情况下，往控制栏追加**常驻功能按钮**：每个按钮点击后只向外发一个信号，功能逻辑由你的游戏在外部实现。

```json
"custom_buttons": [
  {
    "id": "ec_shop_btn",
    "style": "custom",
    "image": "Textures/UI/btn_shop.png",
    "image_active": "Textures/UI/btn_shop_press.png",
    "size": 56,
    "signal": "open_shop",
    "label": "商店"
  }
]
```

- `custom_buttons` 是数组，**可整体不写**（缺省时控制栏只有快进/自动/历史三大按钮，行为与旧版完全一致）。
- 每个按钮对象字段：
  - `id`（必填，string）：UI 组件唯一 id（供 `FindById` / 调试）。
  - `style`（必填，`"custom"` | `"default"`）：`custom` 用 `image` 切图；`default` 用纯色块 + `label` 文字。
  - `image` / `image_active`（custom 必填，default 忽略）：正常态 / 按下态图（复用 `make_btn` 的 `backgroundImage` / `pressedBackgroundImage` + `contain` 适配）。图缺失自动降级 default，不崩。
  - `size`（可选，默认与快进按钮同尺寸）：按钮边长（像素，方形）。
  - `signal`（必填，string）：点击时向外分发的信号名，即 `EC.on_button_pressed` 的 `name`。**无需在 register 预声明**。
  - `label`（default 模式用，可选）：纯色块内显示的文字（emoji / 汉字均可）。
- 按钮排列在三大按钮**之后**，沿用 `control_bar` 的 `spacing` / `margin` / `position`。
- **常驻**：一直挂在屏幕上，不随剧情出现/消失，与三大按钮同生命周期。
- **纯发信号**：点击只触发外部监听，**不前进对话、不进入分支、不触发 `@choice`、不参与 `@signal` 剧本语句、不进存档**。它是一个「功能挂件」，和叙事流完全解耦。

**最简示例（default 纯色块，无需图片资源）**
```json
"custom_buttons": [
  { "id": "ec_shop_btn", "style": "default", "label": "商店", "size": 56, "signal": "open_shop" }
]
```

外部监听见 3.2.3。

### 4.8 UI 定制化：从默认样式到自定义切图

4.7 逐组件列出了每个 UI 元素能配的字段。本节从「怎么定制」的角度，讲清 **default 与 custom 两套样式**的区别、要准备什么图、以及常见坑——让你从「能用」到「和你的游戏画风统一」。

#### 4.8.1 两条路：default 与 custom

每个带 `style` 字段的组件（见 4.7.x）只有两种取值：

| style | 图片要求 | 适用场景 | 优点 / 代价 |
|-------|----------|----------|-------------|
| `"default"` | 无 | 快速验证、原型、没有美术资源时 | 开箱即用，零图片；外观是引擎内置统一风格 |
| `"custom"` | 必须配 `image`（或 `image_normal`/`image_hover`） | 正式上线、要和游戏美术统一 | 完全按你的切图渲染；**图缺失自动降级 default，不崩溃** |

> 一句话：**先 default 把流程跑通，再逐个组件切到 custom 换皮。** 不必一次性全换。

#### 4.8.2 custom 模式要准备什么图

不同组件需要的图字段不一样，对照表（路径都从 `assets/` 起，省略 `assets/`，如 `"Textures/UI/xxx.png"`）：

| 组件 | 需要的图字段 | 是否需要九宫格 |
|------|--------------|----------------|
| dialogue_box | `image` | 是（`nine_slice`） |
| name_tag（仅 above_* 模式） | `image` | 是 |
| choice_button | `image_normal` + `image_hover` | 是 |
| continue_indicator | `image` | 否（小图标） |
| fast_forward_btn | `image` + `image_active` | 否 |
| auto_play_btn | `image` + `image_active` | 否 |
| history_btn | `image` | 否 |
| history_panel | `image` | 是 |
| persistent_filter | `image` | 否（整屏滤镜） |

- **常/悬停/激活** 成对出现的（choice_button、fast_forward_btn、auto_play_btn），建议各做一张，体验更清楚；只给 normal 也能跑，hover 会复用。
- 图片放进 `assets/Textures/UI/` 即可，引用时写相对路径（见 8.4 资源路径）。

#### 4.8.3 九宫格 nine_slice：让底板任意拉伸不变形

对话框、姓名条、选项按钮、历史面板这类「会随屏幕变高变宽」的底板，**必须配 nine_slice**，否则图片被硬拉伸缩、圆角和边框会糊。

```json
"nine_slice": { "top": 16, "bottom": 16, "left": 32, "right": 32 }
```

- 顺序固定为 `{top, bottom, left, right}`，四个值都是「从各边往内多少像素属于不变形区」（像素，设计分辨率体系）。
- 含义：把图切成 3×3 九格，四角完全不动，四条边的**中间段**只做单向拉伸，中心格双向拉伸。所以把圆角、描边放在四角区域，拉伸就只发生在中心。
- 经验值：对话框四角留 16–32px；选项按钮 8–16px 足够。配错（如把 right 写成比图还宽）会显示异常，但不会崩。
- 转换细节（内部）：EC 会把 `{top,bottom,left,right}` 转成 UI 库的 `{left,top,right,bottom}`，你只需按文档顺序填。

#### 4.8.4 降级机制：图找不到也不崩

custom 模式下，如果某张 `image` 在资源里不存在（路径拼错、没导出、忘了放），EC **不会报 ENGINE ERROR 崩溃**，而是自动降级为该组件的 default 样式继续跑，并在日志里提示。这意味着：

- 你不必一次性备齐所有图，缺哪张就先显示默认样式。
- 上线前务必核对每个 `image` 路径真有文件，否则玩家看到的是「混搭风」（部分自定义、部分默认）。

#### 4.8.5 布局自适应：用比例，别用死像素

- 对话框高度用 `panel_height_ratio`（占屏高比例，如 `0.33`），左右留白用 `side_margin`（屏宽百分比字符串，如 `"15%"`）——这两个是**自适应的**，在不同分辨率设备上都合理。
- `text_padding`、`offset`、`font_size`、`height`、`spacing`、`size`、`margin` 等是**设计分辨率体系下的像素**（EC 内部按 1920×1080 设计分辨率缩放），不用你手动按设备换算。
- 控制栏位置用 `position`（`top_left` 等），已默认 `top_left` 规避手机端退出键区域；不要手填绝对坐标压到屏幕角落。

#### 4.8.6 一个完整的 custom 换皮示例

下面是一份把「对话框 + 选项 + 三个控制按钮」都换成 custom 的 `ui_elements` 片段（其余组件省略即走 default）：

```json
"ui_elements": {
  "dialogue_box": {
```

## 五、Easy-ChatBox 剧本语言（DSL）

剧本是一份纯文本（`.txt` 文件或 Lua 字符串），**逐行解析**，每行一种语句。空行和 `#` 开头的行是注释（不执行）。

本节按「功能大类 → 具体语句」两级展开，编号形如 `5.1` / `5.1.1`：

- `5.1`–`5.7` 是七大功能大类（对话与文字、角色控制、场景与音频、效果演出、变量与数据、流程控制、文本样式）。
- `5.x.1` 起是该类下的每条语句详解（格式 / 作用 / 示例 / 注意）。

建议先看 `5.0` 总览建立直觉，写剧本时按 `5.x.y` 查具体写法。

### 5.0 总览

**通用约定**（适用于所有语句）
- 角色 ID、表情名、场景 ID、音频 ID、标签名：英文 / 数字 / 下划线（`[A-Za-z0-9_]`），中文也可作变量/裸字符串。
- 剧本里引用的所有 ID（角色、表情、场景、音频、装饰）**必须先在 `register.json` 登记**，否则校验报错、运行时缺失。
- 文本中的英文双引号 `"` 用 `\"` 转义；换行用 `\n`（注意 `\n` 在字符串里是真换行，会让该句分两行显示）。
- 演出类指令（`@show/@hide/@move/...`）是「即发即走」：**发出后立即开始动画并继续下一行，不会自动等动画播完**。需要等动画，显式写 `@wait`。

**一条最短剧本**
```
@scene bg_classroom fade 1.0
@show alice default center
alice:"你好，我是爱丽丝。"
@end
```

**语句总地图**（按功能）

| 功能分类 | 包含的语句 | 用途 |
|---------|-----------|------|
| 对话与文字 | `角色id:"..."` / `*...` | 角色说话、旁白叙述 |
| 角色控制 | `@show` / `@hide` / `@move` / `@highlight` / `@action` / `@scale` / `@setlayer` | 立绘出场/退场/移动/表情/动作/缩放/层级 |
| 场景与音频 | `@scene` / `@bgm` / `@sfx` | 背景切换、BGM、音效 |
| 效果演出 | `@transition` / `@shake` / `@flash` / `@tint` / `@decoration` / `@textbox` / `@auto` | 黑幕/震动/闪屏/色调/装饰/对话框/自动播放 |
| 变量与数据 | `@set` / `{变量}` | 计数、开关、文本插值 |
| 流程控制 | `@if` / `@choice` / `>` / `>>` / `@call` / `@return` / `@savepoint` / `@wait` / `@end` | 分支、选项、跳转、子剧本、存档、等待、结束 |
| 文本样式 | `[p=...]` / `[color=...]` / `[ital]` / `[bold]` | 对话内的停顿/改色/斜体 |

---

### 5.1 对话与文字类语句

角色说话与系统叙述。

---

#### 5.1.1 对话语句 `角色id:"文本"`

**格式**
```
alice:"你好，我是爱丽丝。"
```
- 必须以**角色 ID**（在 register 的 `characters` 中登记）开头。
- 紧跟英文冒号 `:`，再跟英文双引号包裹的文本内容 `"..."`。
- 角色 ID 与文本之间**必须有引号**，否则解析失败。

**作用**：显示一句带名字的对话。打字机逐字显示；点击可跳过打字 / 推进。

**带表情**
```
alice(happy):"今天天气真好！"
bob(surprised):"真的吗？"
```
- 在角色 ID 后加 `(表情名)`，表情名必须在该角色的 `sprites` 里登记（如 `alice` 的 `happy`）。
- 不写 `(表情)` 时用该角色的 `default_expression`。

**示例**
```
alice:"你好。"
alice(happy):"今天天气真好！"     # 切换到 happy 表情
narrator:"（旁白角色也可用此格式）"  # narrator 需在 register 登记
```

**注意**
- 文本里插变量：`alice:"这是你第{affection_alice}次搭话。"`（见 5.5.1 / 5.3.1）。
- 可夹内联样式标签（见 5.7.1）。

---

#### 5.1.2 旁白语句 `*文本`

**格式**
```
*这是一个平凡的黄昏，夕阳洒进教室。
```
- 以星号 `*` 开头，后面直接跟文本（**不用引号**）。
- 名字栏为空（不会显示角色名），样式与对话区分，不会污染后续对话的姓名显示。

**作用**：叙述性文字、环境描写、心理活动。同样逐字显示。

**显式 narrator 对比**
```
*这是旁白（简写）
narrator:"这也是旁白（显式角色，需在 register 登记为 is_narrator）"
```
两者显示效果类似（narrator 的 `display_name` 通常留空）。推荐用 `*` 简写。

**注意**：`* ` 开头是旁白，**不是注释**。注释用 `#`（见 5.7.2）。

---

### 5.2 角色控制类语句

控制立绘的呈现。所有演出指令即发即走，要等动画就接 `@wait`。

---

#### 5.2.1 显示角色 `@show`

**格式**
```
@show 角色id [表情] [位置] [效果] [时长]
```
参数**顺序任意**，靠名字自动识别：
- 表情：该角色 `sprites` 里存在的键（如 `happy`）。
- 位置：`far_left` / `left` / `center` / `right` / `far_right`。
- 效果：见下方「入场效果表」。
- 时长：纯数字（秒），如 `1.0`。

**作用**：让角色立绘出场，并同时设定表情、位置、入场动画。

**示例**
```
@show alice default center            # 居中、default 表情、无动画（none）
@show alice happy left fade 1.0       # 左、happy、淡入 1 秒
@show bob default right slide_right   # 右、从右滑入（默认时长）
```

**入场 / 出场效果表**（`<effect>`，可用于 `@show` / `@hide`）

| 效果 | 含义 | 默认时长(秒) |
|------|------|------|
| `none` | 直接出现 | 0 |
| `fade` | 淡入 / 淡出 | 0.3 / 0.25 |
| `dissolve` | 溶解 | 0.3 / 0.25 |
| `slide_left` | 从左滑入 / 向右滑出 | 0.5 / 0.4 |
| `slide_right` | 从右滑入 / 向左滑出 | 0.5 / 0.4 |
| `slide_up` | 从下滑入 / 向上滑出 | 0.5 / 0.4 |
| `slide_down` | 从上滑入 / 向下滑出 | 0.5 / 0.4 |
| `zoom_in` | 缩小入场（从 0.63→1.0） | 0.4 / 0.35 |
| `zoom_out` | 放大入场（从 1.2→1.0） | 0.4 / 0.35 |
| `black` | 黑幕转场式 | — |
| `white` | 白幕转场式 | — |

> 时长不写则用上表默认；写了数字则覆盖默认。

**注意**：`@show` 不等待动画。常见写法：
```
@show alice default center slide_left
@wait 0.6                # 等滑入动画播完再说话
alice:"我来了。"
```

---

#### 5.2.2 隐藏角色 `@hide`

**格式**
```
@hide 角色id [效果] [时长]
@hide all [效果] [时长]
```
- 角色 ID 填 `all` 表示隐藏当前全部角色。
- 效果 / 时长同 `@show`（见上表）。

**作用**：让角色退场（淡出 / 滑出等）。

**示例**
```
@hide bob fade 0.5
@hide alice slide_right
@hide all fade            # 全部退场
```

**注意**：退场也是即发即走，需等就写 `@wait`。

---

#### 5.2.3 移动角色 `@move`

**格式**
```
@move 角色id 位置 [时长] [缓动]
```
- 位置：`far_left`/`left`/`center`/`right`/`far_right`。
- 时长：秒（可选，默认 0.8）。
- 缓动：`linear` / `ease_in` / `ease_out` / `ease_in_out`（可选，默认 `ease_in_out`）。

**作用**：把已登场的角色平滑移动到新位置（常用于双角色换位、走入画面）。

**示例**
```
@show alice default center
@show bob default right
@move bob far_right 1.0 ease_in_out    # Bob 移到最右
@move alice left 0.8                   # Alice 移到左
```

**注意**：移动不等待，通常后接 `@wait 时长`。

---

#### 5.2.4 高亮 `@highlight`

**格式**
```
@highlight 角色id
@highlight none
```
- 指定角色 ID：高亮该角色，其余变暗。
- `none`：取消高亮，全部恢复正常亮度。

**作用**：强调当前说话者。常与对话配合：
```
@highlight alice
alice:"听我说……"
@highlight none
```

---

#### 5.2.5 动作 `@action`

**格式**
```
@action 角色id 动作名
```
- 动作名：当前支持 `jump`（跳动）、`shake`（抖动）。其他名字是未知动作（仅警告，不报错）。

**作用**：给角色一个一次性动作动画（比如惊喜时跳一下）。

**示例**
```
@action alice jump
@action bob shake
```

---

#### 5.2.6 缩放 `@scale`

**格式**
```
@scale 角色id [缩放比] [时长] [锚点]
```
- 缩放比：数字，默认 `1.0`（>1 放大，<1 缩小，必须 >0）。
- 时长：秒，默认 `1.0`。
- 锚点：`center`（以中心缩放）或 `feet`（以脚部为基准，立绘更自然），默认 `center`。

**作用**：改变角色大小（强调 / 远景）。

**示例**
```
@scale alice 1.2 0.5 center     # 放大到 1.2 倍，0.5 秒
@scale alice 0.8 0.3 feet       # 缩小，脚部为锚
@scale alice 1.0 0.5            # 复原
```

---

#### 5.2.7 图层 `@setlayer`

**格式**
```
@setlayer 角色id 数值
```
- 数值：整数，越大越靠前（盖在别人上面）。

**作用**：调整多个角色同屏时的前后遮挡关系。

**示例**
```
@setlayer alice 2
@setlayer bob 1          # alice 在 bob 前面
```

---

### 5.3 场景与音频类语句

背景切换与声音。

---

#### 5.3.1 场景切换 `@scene`

**格式**
```
@scene 场景id [转场效果] [时长]
```
- 场景 ID：register 的 `scenes` 中登记。
- 转场效果：省略时用该场景在 register 里配的 `transition`；都不写则默认 `fade`。
- 时长：秒（可选）。

**作用**：切换背景 / CG。

**示例**
```
@scene bg_classroom fade 1.0       # 教室，1 秒淡入
@scene bg_campus dissolve 1.5      # 校园，溶解
@scene cg_confession               # CG，用 register 里配的 transition/duration
```

**转场效果说明**
- `none`：直接切换，无动画。
- `fade`：交叉淡入（旧图淡出、新图淡入）。
- `black` / `white`：遮罩转场（先淡入黑/白幕，换图，再淡出）。

---

#### 5.3.2 音频 `@bgm` / `@sfx`

**@bgm 格式**（BGM 常驻循环）
```
@bgm 音频id                  # 播放（用 register 注册音量）
@bgm 音频id 音量             # 播放并指定音量(0–1)
@bgm stop [淡出时间]         # 停止（淡出时间秒，默认 0）
@bgm fade 目标音量 [渐变时间] # 在渐变时间内把音量降到目标（默认 0.3 / 0.5s）
@bgm unfade                  # 恢复到该 BGM 的 register 注册音量
```
- 音频 ID 必须在 register 的 `audios` 里且 `type:"bgm"`，否则警告。
- `fade` 的「目标音量」是临时压低（如演出安静时），`unfade` 恢复注册值。

**@sfx 格式**（音效一次性）
```
@sfx 音频id                  # 播放（用 register 音量）
@sfx 音频id 音量             # 指定音量(0–1)
```
- 音频 ID 必须在 register 的 `audios` 里且 `type:"sfx"`。

**示例**
```
@bgm bgm_daily 0.7
@sfx sfx_door_open
@bgm fade 0.2 1.0            # 对话间隙压低 BGM
@bgm unfade                  # 恢复
@bgm stop 1.0                # 章节结束停 BGM
```

---

### 5.4 效果演出类语句

全屏或全局的演出氛围。任意时刻只能有一种 `@tint`；`@decoration` 是临时层，常驻滤镜请用 `ui_elements.persistent_filter`。

---

#### 5.4.1 转场与全屏特效

| 指令 | 格式 | 作用 |
|------|------|------|
| 黑幕转场 | `@transition 效果 [时长]` | 全屏黑/白幕淡入淡出。常用 `fade_in` / `fade_out`；也可 `iris_out` 等。时长秒。 |
| 震动 | `@shake [强度] [时长]` | 屏幕震动。强度默认 1.0，时长默认 0.3s。 |
| 闪白/闪色 | `@flash 颜色 [时长]` | 全屏闪一下。颜色 `white/black/red/green` 或 `#RRGGBB`，时长默认 0.3s。 |
| 色调 | `@tint ...` | 给全屏叠一层颜色（见下）。 |
| 装饰滤镜 | `@decoration 装饰id [时长]` | 显示全屏装饰（暗角/飘雪等）；`@decoration none` 清除。时长默认 0.5s。 |
| 对话框显隐 | `@textbox show` / `@textbox hide` | 显示/隐藏对话框。 |
| 自动播放 | `@auto on` / `@auto off` / `@auto speed 秒数` | 开启/关闭自动播放；`speed` 设每句停留秒数。 |

**@tint 四种形态**
```
@tint 颜色 不透明度 时长          # 设置并淡入，之后保持该不透明度
@tint 颜色 on 时长                # 开启常驻色调（淡入时长=时长），直到被覆盖/关闭
@tint 颜色 不透明度 on 时长       # 同上，并指定不透明度
@tint off 时长                    # 关闭/淡出清除（也可写 @tint none 时长）
```
- 颜色：`white/black/red/green` 或 `#RRGGBB`。
- 不透明度：0–1。
- 任意时刻**只能存在一种色调**；新 `@tint` 覆盖旧的。
- `@decoration` 是剧情临时层（可多次切换/清除）；初始化后常驻滤镜请用 `ui_elements.persistent_filter`（见 4.7.9），二者不要混用。

**示例**
```
@transition fade_out 2.0          # 结尾黑幕
@shake 16 0.5                     # 地震
@flash white 0.3                  # 闪白
@tint red 0.3 0.5                 # 淡淡红晕
@tint black on 1.0                # 常驻压暗
@tint off 0.5                     # 解除
@decoration vignette 0.5          # 暗角装饰
@decoration none                  # 清除装饰
@textbox hide                     # 隐藏对话框（如纯演出时）
@auto on                          # 自动播放
```

**注意**：`@textbox style` 已弃用（v0.1.23），写了只警告、忽略；样式由 register 的 `ui_elements.<comp>.style` 控制。

### 5.5 变量与数据类语句

驱动分支、计数、插值的「记忆」。

---

#### 5.5.1 变量与插值 `@set` / `{变量}`

**@set 格式（两种写法）**

旧写法（简短）：
```
@set 变量名 +数值        # 数值型：加（变量须是数字，默认 0）
@set 变量名 -数值        # 数值型：减
@set 变量名 true         # 设为布尔 true
@set 变量名 false        # 设为布尔 false
@set 变量名 字符串/数字   # 直接赋值（数字自动转 number，否则字符串）
```
新写法（表达式）：
```
@set 变量名 = 表达式      # 表达式结果赋值
@set 变量名 += 表达式     # 原值 + 表达式
@set 变量名 -= 表达式     # 原值 - 表达式
```

**作用**：修改变量，驱动分支、插值、计数。

**插值 `{变量名}`**：对话 / 旁白文本里用花括号夹变量名，运行时替换为当前值。
```
@set affection_alice +1
alice:"这是你第{affection_alice}次和我搭话了。"
```
- 未定义变量显示为 `{原名}`（不崩）。
- 变量可在 register 的 `variables` / `flags` 预声明，也可在剧本里用 `@set` 首次创建（无需预声明，且能在 `@if` 条件里直接用）。

**表达式支持**（用于 `=`/`+=`/`-=` 右侧）
- 算术：`+ - * / %`
- 字符串拼接：`..`（如 `"第" .. day .. "天"`）
- 比较：`> >= < <= == !=`（返回布尔）
- 逻辑：`&& || !`
- 括号分组：`(a + b) * 2`
- 字面量：数字、用引号包裹的字符串、 `true` / `false`
- 标识符：变量名，或中文等作裸字符串

**示例**
```
@set affection_alice +1
@set met_bob true
@set score = affection_alice * 2 + 10
@set title = "第" .. day .. "章"
@set flag = met_bob && affection_alice >= 3
```

### 5.6 流程控制类语句

决定剧情「走哪条路、何时停、何时结束」。

---

#### 5.6.1 条件分支 `@if` / `@else if` / `@else` / `@endif`

**格式**
```
@if 条件
    ...语句...
@else if 条件
    ...语句...
@else
    ...语句...
@endif
```
- `@if` 后跟条件表达式（见 5.5.1 的表达式规则；可用变量、数字、字符串、`&& || !`、`()`）。
- `@else if` 可多个；`@else` 最多一个且放最后。
- 必须以 `@endif` 闭合，否则校验报错。
- 条件为 `false` 的分支整段跳过，不执行其中语句。

**作用**：根据变量值走不同剧情。

**示例**
```
@if affection_alice >= 5
    alice(happy):"你对我真好！"
@else if affection_alice >= 2
    alice:"你来得正好。"
@else
    alice(sad):"我们好像还不熟……"
@endif
```

**嵌套**
```
@if met_bob
    @if affection_alice >= 3
        alice:"老朋友！"
    @else
        alice:"好久不见。"
    @endif
@endif
```

---

#### 5.6.2 玩家选择 `@choice` … `@end`

**格式**（块结构，必须 `@choice` 开头、`@end` 结尾）
```
@choice
- "选项文本" >> 目标标签
- "选项文本" >> 目标标签 @if 条件
@timeout 秒数 >> 超时标签
@end
```
- 每个选项：`- "文本" >> 标签名`。`>>` 后是跳转目标（必须在剧本里用 `>` 定义，见 5.6.3）。
- 选项后可加 `@if 条件`：条件不满足则该选项**不显示**（仍可点其他选项）。
- `@timeout 秒数 >> 标签`（可选）：倒计时内玩家没选，自动跳到该标签。
- 所有选项的 `@if` 都不满足时，**整个 `@choice` 块被跳过**（不卡死）。

**作用**：弹出选项，玩家用鼠标点击或键盘 1–4 选择；选后跳到对应标签继续。

**示例**
```
@choice
- "好啊，一起去！" >> choice_library
- "抱歉，周末有事……" >> choice_busy
- "图书馆？去干嘛？" >> choice_ask @if met_bob
@timeout 8 >> choice_timeout
@end

> choice_library
alice(happy):"太好了！"
>> after_choice
> choice_busy
alice(sad):"下次吧。"
>> after_choice
> choice_timeout
*你沉默不语。
>> after_choice
> after_choice
@wait 0.3
```

**注意**
- 选项至少 1 个；每个选项必须有 `>> 标签`。
- 标签跳转目标必须存在（单 `>` 定义，双 `>>` 跳转）。
- `@choice` / `@end` / `@timeout` **只能在 choice 块内使用**；块外写 `@end` 会被当作「结束剧本」指令（见 5.6.5）。

---

#### 5.6.3 标签与跳转 `>` / `>>`

**格式**
```
> 标签名          # 定义标签（单行 > ）
>> 标签名         # 跳转到标签（双行 >> ）
```
- 词法上**先匹配 `>>`** 再匹配 `>`：写跳转务必用双 `>`，定义用单 `>`。
- 标签名任意（建议英文 / 下划线），必须在当前剧本（同一文件）内唯一。

**作用**
- `>` 定义一个落点，本身不执行任何事，只是位置标记。
- `>>` 无条件跳到该标签，常用于分支汇合、循环、重试。

**示例（分支汇合）**
```
@choice
- "A" >> branch_a
- "B" >> branch_b
@end
> branch_a
alice:"选了 A。"
>> merge
> branch_b
alice:"选了 B。"
>> merge
> merge
@wait 0.5
*（无论选 A 还是 B，都汇合到这里继续）
```

**示例（循环重试）**
```
> quiz_start
alice:"1+1=?"
@choice
- "2" >> quiz_right
- "3" >> quiz_wrong
@end
> quiz_wrong
alice:"不对，再想想。"
>> quiz_start          # 跳回重来
> quiz_right
alice:"答对啦！"
```

**注意**：跨文件跳转（`>> 文件:标签`）当前不支持。子剧本跳转见 5.6.4。

---

#### 5.6.4 子剧本 `@call` / `@return`

**格式**
```
@call 文件名
...（当前剧本后续）...
```
- 在子剧本末尾写 `@return` 返回调用处。

**作用**：把通用段落（问候、教学）抽到子剧本，主剧本用 `@call` 复用；支持多层嵌套（调用栈自动管理）。

**使用方式**：子剧本源码通过 `EC.start` 的第四个参数 `sources` 传入：
```lua
local sources = {
    common_greeting = 'alice:"你好。"\n@return',
    tutorial        = 'bob:"操作说明……"\n@return',
}
EC.start(nil, main_chat, "chapter1", sources)
```
剧本里：
```
@call common_greeting
alice:"（上面那段是公共问候）"
```

**注意**：`@call` 的 `文件名` 必须在 `sources` 表里存在，否则报错跳过。

---

#### 5.6.5 结束 `@end`

**格式**
```
@end
```
- 单行指令。

**作用**
- 在 `@choice` 块**外**：结束当前剧本。若处于顶层 → 触发结束信号（见 3.2）；若处于子剧本（`@call` 内）→ 回到调用处继续主剧本。
- 整个剧本顺次执行到最后一行，等价于隐式 `@end`，同样触发结束信号。

**注意**：`@choice` 块**内**的 `@end` 是「关闭选项块」的语法，不是结束剧本（见 5.6.2）。两者上下文不同，解析器会自动区分。

---

#### 5.6.6 等待 `@wait`

**`@wait 格式**
```
@wait 秒数
```
- 秒数：数字（如 `0.5`、`1.0`）。

**作用**：暂停剧情指定秒数。常用于：
- 等演出动画播完（`@show`/`@move` 之后）。
- 旁白/对话之间留停顿，让玩家看清。
- 配合 `@transition` 等特效。

**示例**
```
@show alice default center slide_left
@wait 0.6
alice:"我来了。"
@wait 1.0
*（留 1 秒空镜）
```

---

#### 5.6.7 存档点 `@savepoint`

**格式**
```
@savepoint
```
- 单行指令，无参数。

**作用**：标记一个存档点。运行时**第一次**到达该点执行「存档」（记录变量、指令位置、调用栈）；**之后**每次再到达则「读档」（恢复到第一次的状态）。用于「本段可重试」——玩家失败/选错后回到该点重来，变量也复位。

**示例**
```
> quiz_start
@savepoint                  # 标记存档点
alice:"开始答题。"
@choice
- "提交" >> quiz_submit
@end
> quiz_submit
@if score < 60
    alice:"不及格，再来一次。"
    >> quiz_start          # 跳回，会读档复位
@else
    alice:"通过！"
@endif
```

**注意**：存档状态由 EC 内部持有（首次存、之后读），外部无需干预；外部存档仍用 `EC.export_globals / import_globals`（见第七章）。

---

### 5.7 文本样式类标签

写在对话 / 旁白文本**内部**，与 `{变量}` 可混用。

---

#### 5.7.1 内联富文本标签

在对话 / 旁白文本里可用（与 `{变量}` 可混用）：

| 标签 | 格式 | 作用 |
|------|------|------|
| 停顿 | `[p=0.5]` | 打字到此处停顿 0.5 秒（打字机节奏）。 |
| 改色 | `[color=#RRGGBB]文字[/color]` | 区间局部改色。支持 `#RRGGBB` 与色名 `red/green/blue/yellow/white/cyan/orange`。 |
| 斜体 | `[ital]文字[/ital]` | 区间局部斜体。 |
| 粗体 | `[bold]` / `[/bold]` | 兼容写法，正文默认已粗体，标签本身不产生额外样式（可留作占位）。 |

**示例**
```
alice:"等一下[p=0.8]你说什么？[color=#FF0000]不可能！[/color]"
*旁白里也能用[ital]斜体[/ital]和[color=#6BB5FF]蓝字[/color]。
bob:"[color=#FFD700]警告[/color]：前方有危险[p=1.0]……"
```

**注意**
- 标签必须在文本内成对（如 `[color=...]...[/color]`），否则样式作用到句末。
- `[p=N]` 的停顿点不可被点击跳过（点击只跳过打字，不跳过 `[p]` 停顿；再点一次才继续）。

---

#### 5.7.2 注释 `#`

**`#` 注释格式**
```
# 这是一行注释，不会被执行
```
- 以 `#` 开头的整行被忽略（不显示、不执行）。
- 可用于标注段落、调试说明。

**注意**：`* 开头是旁白`，`# 开头才是注释`。不要把旁白写成注释。

**示例**
```
# ===== 第 1 章：相遇 =====
@scene bg_classroom fade 1.0
*夕阳洒进教室。（这是旁白，会显示）
```

### 5.8 向外部发送信号 @signal

**格式**
```
@signal 信号名
```
- 单行指令，紧跟一个信号名（任意字符串，可中英文）。
- 只取第一个参数：`@signal foo bar` 只发 `foo`，其余被忽略。
- 信号名**无需在 register.json 预声明**（自由字符串）。

**作用**：在剧情执行到这一行时，向**外部游戏**发一个信号，让外部监听并做出反应（弹窗、刷怪、更新任务等）。详见 3.2.2 的外部接线说明。

**示例**
```
@show alice default center
alice:"任务开始。"
@signal quest_start          # 外部收到 quest_start → 弹 toast / 开任务
@wait 1.0
alice:"敌人出现了！"
@signal enemy_spawn          # 外部收到 enemy_spawn → 刷怪
@wait 1.0
alice:"阶段完成。"
@signal phase_clear          # 外部收到 → 结算
@end
```

**行为要点**
- **fire-and-forget**：发出后立刻执行下一行，不阻塞剧情、不等待外部回应。
- **快进也触发**：自动播放 / 快进下照常发出（即发即走）。
- **不去重**：同一条 `@signal NAME` 每执行一次就发一次；循环 / 分支里多次执行会发多次。
- **不进存档**：信号无状态，不参与 `@savepoint` 存档。
- **无监听则静默**：剧本发了但外部没 `EC.on_signal` 注册该名的信号，会被静默丢弃（不报错、不崩）。
- 连续两行信号（如 `@signal a` 紧接 `@signal b`）在相邻帧（普通播放）或同帧（快进）触发，外部按书写顺序依次收到。

**注意**：`@signal` 与「结束信号」是两条独立通道——它不是剧情结束，只是中途的一次通知。一段剧情可以发任意多次 `@signal`，且可以早于 `@end` 之前很久就发。

## 七、存档与跨剧本共享

EC 本身**不持有存档**。存档由你的游戏负责，EC 只提供导入 / 导出接口。

**典型流程**（剧情 → 外部玩法 → 重新进入剧情）：

```lua
-- 进入剧情前：把上次导出的变量塞回去
EC.import_globals(saved_variables)          -- 必须在 EC.start 之前
EC.start(nil, chat_source, "chapter2")

-- 剧情结束时（on_finished 回调里）：导出变量存到你自己的存档
EC.on_finished(function(name)
    saved_variables = EC.export_globals()   -- 含 affection_alice 等
    -- 连同你的游戏进度一起写盘
end)
```

- `EC.export_globals()` 返回变量表的副本，外部修改不会污染内部。
- `EC.import_globals(tbl)` 整体覆盖初始值；`tbl=nil` 则不覆盖（用 register 默认）。
- 一个存档 = 一张变量表，**不跨存档共享**。
- 历史记录用 `EC.clear_history()` 在切换剧情 / 新存档时清空。

#### 7.1 CG 解锁状态（玩家级，独立于变量表）

CG 解锁是「见过即永久」的玩家收集进度，**只和玩家有关、跨剧情与跨存档保留**，不混入 `variables` 变量表（避免被剧本 `@set` 误改）。它走独立的 import / export：

```lua
-- 玩家进入游戏 / 读档时：把上次导出的 CG 表塞回（应在 EC.start 之前）
EC.import_cg_status(saved_cg_status)        -- saved_cg_status=nil 表示新玩家，重置为全 false

-- 剧本里播到 @scene cg_xxx 会自动解锁（见 4.3），无需手动调用

-- 玩家存档 / 退出剧情时：导出 CG 表随玩家存档写盘
EC.on_finished(function(name)
    saved_cg_status = EC.export_cg_status()  -- { cg_confession=true, ... }
    -- 连同 saved_variables、游戏进度一起写盘
end)

-- CG 回看界面查询
local all_status = EC.get_cg_unlock_status()  -- 全量 {id=bool}，未解锁为 false（灰显用）
local unlocked   = EC.get_unlocked_cgs()      -- 已解锁 id 数组（遍历展示用）
```

- `EC.import_cg_status(tbl)`：`tbl` 非 nil 整体覆盖；`tbl=nil` 重置（下次 `start` 由 register 的 `type=="cg"` 场景重建为全 `false`）。
- 新增 CG（register 加了新场景）：再次 `start` 时自动补该键为 `false`，**不会清除已有解锁**。
- CG 解锁**不可逆**（不支持主动 set），保证收集进度真实反映玩家走过的内容。

## 八、调试与常见问题

### 8.1 启动时看日志

EC 启动时会打印加载信息：`[EasyChat] 加载完成: chapter1 (N AST → M 指令)`。
若剧本有错，会打印 `[EasyChat] 错误: ...` 和 `[EasyChat] 警告: ...`，按行号定位。

### 8.2 常见错误

| 现象 | 原因 / 解决 |
|------|------|
| `角色 'xxx' 未注册` | 剧本里的角色 ID 没在 `register.json` 的 `characters` 登记。 |
| `角色 'alice' 没有注册表情 'happy'` | `alice(happy)` 的 `happy` 不在该角色 `sprites` 里。 |
| `场景 'xxx' 未注册` / `音频 'xxx' 未注册` | 对应 ID 没在 `register.json` 登记。 |
| `选项跳转目标 '> xxx' 不存在` | `@choice` 里的 `>> xxx` 标签没定义（注意单 `>` 是定义，双 `>>` 是跳转）。 |
| `未闭合的 @choice` | `@choice` 块缺少 `@end`。 |
| UI 在手机上错位 | 宿主没用 `UI.Scale.DESIGN_RESOLUTION(1920,1080)` 初始化，或用了别的缩放值。 |
| 结束信号没触发 | 没调 `EC.on_finished(fn)`，或 fn 不是 function。 |
| 动画「要点一下才动」 | 其实动画是自动播放的；若看起来卡住，多半是旁白处于 `waiting_click` 状态，点一下推进的是旁白本身。确认 `@show` 后面是否漏了 `@wait`。 |

### 8.3 校验规则速记

- 所有 `@show/@hide/@scene/@bgm/@sfx/@decoration` 引用的 ID 必须在 register 登记。
- 标签跳转目标必须存在（跨文件跳转目前不支持 `文件:标签` 写法）。
- `@choice` 至少要有一个选项；选项必须带 `>> 标签`。
- `@set` 新建的变量无需预声明，可直接在 `@if` 条件里用。
- 校验只有「警告」不阻断运行；有「错误」则剧本不会启动。

### 8.4 资源路径

- 资源放在 `assets/` 下，引用时从 `assets/` 下一级开始写，例如 `Textures/UI/btn_ff_normal.png`。
- 不要写 `assets/...` 前缀。
- custom 样式图片缺失会自动降级为 default，不会崩。
